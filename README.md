# 📊 Следило

**Трекер экранного времени с матными напоминаниями.**

Следило показывает, сколько времени ты проводишь в каждом приложении. Если какое-то приложение юзается больше порога — прилетает push с дерзким текстом. Всё работает **локально**, без серверов и аккаунтов.

## ✨ Возможности

- **📱 Список приложений** — сколько времени ты провёл в каждом приложении за сегодня
- **🔔 Умные уведомления** — если приложение юзается дольше порога, прилетает push с матным текстом, зависящим от времени суток
- **🎛 Конструктор фраз** — 12 готовых шаблонов + свои. Подставь `{app}` и `{hours}` — заменятся автоматически
- **🚫 Режим без мата** — переключатель для вежливых напоминаний
- **⚙️ Настройка порога** — слайдер от 1 до 12 часов
- **📈 Почасовой график** — тапни на приложение, увидишь активность по часам
- **📲 Виджет** — топ-3 приложения и общее время на рабочем столе
- **🔄 Автопроверка обновлений** — приложение само стучится на GitHub и предлагает обновиться
- **🔒 Приватность** — все данные только на устройстве

## 🚀 Установка

1. Скачай последний APK из раздела [**Releases**](https://github.com/averinger/sledilo/releases/latest)
2. Открой файл на телефоне и разреши установку из неизвестных источников
3. Запусти приложение и дай разрешение на **«Доступ к данным об использовании»**
4. Готово

## 📜 Что было по пути

Этот проект собирался **полностью на Android-планшете, без ПК, без Android Studio** — прямо в Termux. По пути было много боли и решений:

- **AAPT2 на ARM** — Gradle по умолчанию тянет x86-бинарник, который падает. Решение: явный override через `android.aapt2FromMavenOverride`
- **OkHttp 4.x и SELinux** — на кастомной прошивке планшета библиотека падала с `EPERM` при инициализации. Откат на 3.12.13 решил проблему
- **Проверка обновлений через GitHub API** — используем `HttpURLConnection`, потому что OkHttp 4.x не работает
- **Виджет через RemoteViews** — Compose в виджетах не работает, пришлось собирать на XML с ограничениями
- **Иконки через ImageMagick** — генерим PNG для всех плотностей + adaptive-icon XML
