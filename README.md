# 📊 Следило

**Трекер экранного времени с матными напоминаниями.**

Следило показывает, сколько времени ты проводишь в каждом приложении. Если какое-то приложение юзается больше 5 часов в день — прилетает push с дерзким текстом. Всё работает локально, без серверов и аккаунтов.

## 🎯 Что умеет

- 📱 **Список приложений** — сколько времени ты провёл в каждом приложении за сегодня
- 🔔 **Умные уведомления** — если приложение юзается 5+ часов, прилетает push с матным текстом:
  - Днём: «Ты в "TikTok" уже 5 часов, братан. Может хватит?»
  - Вечером: «"TikTok" 5 ч. Вечер, а ты всё там же. Помойся уже»
  - Ночью: «Ночь, а ты в "TikTok" 5 ч. Ты вообще нормальный?»
- 📈 **Почасовой график** — тапни на приложение, увидишь в какие часы ты был активен
- 🎨 **Мини-графики** — под каждым приложением полоса-прогресс от максимума за день
- 🔒 **Приватность** — все данные хранятся только на устройстве. Никаких серверов, аккаунтов и аналитики

## 🚀 Установка

1. Скачай последний APK из раздела **Releases**
2. Открой файл на телефоне и разреши установку из неизвестных источников
3. Запусти приложение и дай разрешение на **Доступ к данным об использовании**
4. Готово — приложение начнёт следить за твоим экранным временем

## 🛠️ Стек

- **Kotlin**
- **Jetpack Compose** — декларативный UI
- **WorkManager** — фоновые задачи для уведомлений
- **UsageStatsManager** — системный API Android для чтения статистики

## 📋 Требования

- Android 7.0+ (API 24+)
- Разрешение PACKAGE_USAGE_STATS (даётся вручную в настройках)

## 🧑‍💻 Сборка из исходников

    git clone https://github.com/averinger/sledilo.git
    cd sledilo
    ./gradlew assembleDebug

APK будет в app/build/outputs/apk/debug/
